# eCommerce Backend API 🛍️  

This is the backend of a full-stack eCommerce web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It manages user authentication, product management, order processing, and payments.

## 🚀 Technologies Used  

### Backend Stack:  
- 🌐 **Node.js** - JavaScript runtime environment  
- 🖧 **Express.js** - Web framework for handling routes and middleware  
- 🗄️ **MongoDB** - NoSQL database for storing data  
- 🔐 **JWT & bcrypt** - Secure authentication and password hashing  
- 📦 **Mongoose** - MongoDB object modeling for schema-based data  
- 🛒 **Razorpay** - Payment gateway integration  
- 📩 **Nodemailer** - Email notifications for order confirmations  

## ✨ Features  

### 🔐 User Authentication  
- Users can register, log in, and manage their profiles.  
- Secure password storage using **bcrypt**.  
- JWT-based authentication for protected routes.    

### 🛒 Shopping Cart  
- Users can add/remove products and adjust quantities.  
- Session-based or database-stored cart for seamless shopping experience.  

### 💳 Checkout & Payment  
- Seamless checkout process with **Razorpay** payment gateway.
